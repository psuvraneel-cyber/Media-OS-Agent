# Media Intelligence OS — Roadmap

**Authoritative as of 2026-11-14.** Supersedes the phase ordering in the README and PRD (Phases 6–10 are
re-sequenced below). Detailed Phase 5 milestones: `docs/PHASE_5_COMPLETION_PLAN.md`.
Nimontron facts: `docs/brands/nimontron/BRAND_BRIEF.md`.

## Goal (owner, 2026-11-14)

1. **Market Nimontron** (Bengali invitation-card app) from one Instagram + Facebook account (carousels,
   occasional Reels) and one YouTube channel (Shorts + long-form). Content is generated by the agent
   (Gemini), reviewed, scored, and published through Postiz.
2. **Learn from performance:** read each account's stats, find which formats, hooks and topics work,
   and steer new content toward them while still testing new ideas.
3. **Run a standalone tech Instagram page** fed by the research pipeline (AI trends, tech news,
   open-source GitHub repositories).

Personal use only. **Zero budget:** no paid billing on any AI provider. Free tiers only, with lawful
failover across *different* providers when one tier's quota is used up (never multiple keys or
accounts on one provider to evade its limits). Nimontron is live on Google Play (34 installs as of
2026-11-14).

## Guardrails that stay in force

- Only claims from the brand brief's approved list; no invented features, prices, rankings or reviews.
- Postiz stays separate; publishing only through its Public API or MCP.
- Approval gate on by default; per-account posting caps; no identical cross-account reposting.
- No Gemini key rotation to evade quotas; daily budget stop.
- Reddit stays BLOCKED; research sources use official APIs and feeds only.
